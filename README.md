# argon2-rust-cli

Generate Argon2 hashes from the command line, powered by the pure-Rust
[`argon2-rust`](https://crates.io/crates/argon2-rust) implementation.

This is a fork of [`argon2-cli`](https://github.com/Systemscape/argon2-cli) by
Joel Schulz-Andres and Julian Dickert. The command-line interface is kept
compatible with the original; the hashing backend was replaced with
`argon2-rust`.

## Installation

```bash
cargo install argon2-rust-cli
```

Or via [`cargo-binstall`](https://github.com/cargo-bins/cargo-binstall):

```bash
cargo binstall argon2-rust-cli
```

## Usage

```bash
echo -n "password" | argon2-rust-cli
```

This CLI accepts the password via `stdin`, which avoids putting the password in
shell history.

### Options

```
argon2-rust-cli [-h] [salt] [-i|-d|-id] [-t iterations] [-m log2(memory in KiB) | -k memory in KiB] [-p parallelism] [-l hash length] [-e|-r] [-v (10|13)]
```

- `[salt]` Optional explicit salt; must be at least 8 characters long
- `-i` Use Argon2i (default)
- `-d` Use Argon2d
- `-id` Use Argon2id
- `-t` Number of iterations (default: 3)
- `-m` Memory usage of 2^N KiB (default: 12)
- `-k` Memory usage of N KiB (default: 4096)
- `-p` Parallelism threads (default: 1)
- `-l` Hash output length in bytes (default: 32)
- `-e` Output only encoded hash
- `-r` Output only raw bytes
- `-v` Argon2 version (default: 13)

## Examples

```bash
# Basic usage (random salt generated automatically)
echo -n "password" | argon2-rust-cli

# With explicit salt
echo -n "password" | argon2-rust-cli somesalt

# Use Argon2id with custom parameters
echo -n "password" | argon2-rust-cli somesalt -id -t 4 -m 16 -p 4

# Output only encoded hash
echo -n "password" | argon2-rust-cli somesalt -e
```

## Compatibility

This CLI strives for interface compatibility with the
[C reference implementation](https://github.com/P-H-C/phc-winner-argon2), but
does not guarantee it. Deviations are made where the original interface
significantly hinders usability. For example, the salt is optional in this
implementation and a cryptographically secure random salt is generated by
default. This CLI also accepts the password via `stdin`, unlike the standard
Linux `argon2` CLI, which helps avoid leaking passwords into shell history.

The PHC-encoded output is compatible with the C reference and with other Argon2
implementations. Integration tests compare encoded and raw output against the
reference `argon2` binary when it is available on `PATH`.

## Performance

The `argon2-rust` backend uses runtime-dispatched SIMD (AVX-512, AVX2, SSE2
or NEON, with a scalar fallback), so the same binary runs everywhere and picks
the fastest path supported by the CPU.

Wall-clock means from `hyperfine` on an Intel Core i5-12500H, Linux 7.2.15,
with a fixed password and salt and `-e` output:

| Parameters | `argon2-rust-cli` | `argon2-cli` (upstream) | C reference `argon2` |
|---|---:|---:|---:|
| Argon2id, 4 MiB, t=3, p=1 | **10.3 ms** | 12.3 ms | 13.8 ms |
| Argon2id, 64 MiB, t=3, p=4 | **49.3 ms** | 151.4 ms | 88.9 ms |
| Argon2d, 16 MiB, t=5, p=1 | **46.4 ms** | 64.8 ms | 68.4 ms |

Lower is better. Timings vary by machine, CPU frequency and system load; run
`hyperfine` locally if you need numbers for your hardware.
